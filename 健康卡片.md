# 健康卡片Schema

## 一、设计原则回顾（来自材料）

1. **每日对话抓动态，导出表单填静态** ：日常记录只提取聊天中自然出现的内容；既往病史、手术史等静态数据在导出报告时由用户手动填写（「我的资料」已填的出生年份、既往病史、手术史自动带入，未填则导出时补填）。
2. **报告 = 静态表单 + 动态记录聚合** ：症状频率、程度、趋势等由半年内每日记录自动统计，用户只需在导出时确认。
3. **记录不是诊断** ：只做事实整理，不做医学判断。
4. **关键词归一、处理否定与趋势** ：同义词映射到规范名，否定词（没有/不）标记 `occurred: false`，趋势词（加重/减轻）写入 `trend`。

## 二、健康卡片条目 Schema 定义（按类别）

1. ### 身体症状（SymptomRecord）——最高频核心

 **适用场景** ：潮热、盗汗、心悸、疲劳、头痛、关节痛等（见2.1规范名列表）。

 **字段设计** （可数值化，支撑月历曲线与报告统计）：

| 字段      | 类型    | 说明                                                            | 数值化/曲线支持                                |
| --------- | ------- | --------------------------------------------------------------- | ---------------------------------------------- |
| symptom   | string  | 规范名（如“潮热”），同义词归一后存储                          | 分类维度                                       |
| occurred  | boolean | 当天是否发生（处理否定：“今天没有潮热”→false）               | 计算发生天数/频率                              |
| severity  | enum    | 程度："轻" / "中" / "重"                                        | 程度分布、趋势曲线                             |
| frequency      | string  | 频率描述：如 "3次"、"经常"、"偶尔"                    | 原始描述                                          |
| frequencyCount | number  | 次数数值槽："3次"→3、"一天两次"→2；模糊词不解析、留空 | 潮热次数/天曲线主数据源；无值回退 severity 等级绘图 |
| trend     | enum    | 趋势："加重" / "减轻" / "稳定"（从“越来越…”等词提取）        | 趋势变化曲线                                   |
| trigger   | string  | 诱因（如“下午喝了咖啡”）                                      | 归因分析                                       |
| quote     | string  | 原文片段，用于确认回显                                          | 复核                                           |

> **针对您的疑问** ：
>
> * 潮热 = `frequency`（每日次数描述）+ `frequencyCount`（次数数值）+ `severity`（程度） + `occurred` + `trend`。
> * 若用户说“今天潮热5次，很难受”，则 `frequency:"5次"`, `frequencyCount:5`, `severity:"重"`。
> * 月历曲线优先用 `frequencyCount` 数值绘制；无数值时（“经常/偶尔”）降级用 `severity` 等级做可视化。

---

2. ### 睡眠（SleepRecord）

 **字段设计** （睡眠是独立卡片，非症状子属性）：

| 字段       | 类型   | 说明                           | 数值化支持              |
| ---------- | ------ | ------------------------------ | ----------------------- |
| quality    | enum   | 睡眠质量："好" / "一般" / "差" | 可直接映射为1-3分画曲线 |
| bedtime    | string | 入睡时间（如 "23:30"）         | 时长计算                |
| wakeTime   | string | 醒来时间                       | 时长计算                |
| nightWakes | number | 夜间醒来次数（整数）           | 量化睡眠中断            |
| detail     | string | 症状描述：入睡难/早醒/多梦等   | 报告文本                |

> **针对您的疑问** ：睡眠不是单一“小时数”或“好/中/差”，而是 **时长（由bedtime/wakeTime算）+ 质量等级 + 夜醒次数** ，三者结合可生成丰富的睡眠曲线。

---

3. ### 情绪（MoodRecord）

| 字段        | 类型   | 说明                       | 数值化支持 |
| ----------- | ------ | -------------------------- | ---------- |
| type        | enum   | "负面" / "正面"            | 可计数     |
| description | string | 具体情绪词（烦躁、开心等） | 分类       |
| trigger     | string | 诱因（和谁/什么事有关）    | 归因       |

> **针对您的疑问** ：心情**不做 Kupperman 等量表映射**（与“记录不是诊断”原则一致）：日常对话抓取先存文本，曲线与报告以“正面/负面”计数和情绪词展示，导出时由用户确认，不自动映射为医学评分等级。

---

4. ### 月经与出血（MenstrualRecord）——低频率高价值

| 字段          | 类型   | 说明                                                                            | 数值化支持                       |
| ------------- | ------ | ------------------------------------------------------------------------------- | -------------------------------- |
| event         | enum   | "来了" / "没来" / "量多" / "量少" / "淋漓不尽" / "非经期出血" / "痛经" / "停经" | 状态机                           |
| date          | string | 发生日期（YYYY-MM-DD）                                                          | 时间锚点                         |
| daysSinceLast | number | 距上次多久（天）                                                                | 计算周期长度，支撑月经规律性曲线 |
| note          | string | 伴随不适                                                                        | 报告                             |

---

5. ### 其他动态类别（简要字段）

| 类别                         | 关键字段                                        | 说明                                             |
| ---------------------------- | ----------------------------------------------- | ------------------------------------------------ |
| 体重 (WeightRecord)          | direction: "增加"                               | "减少", amount: string（如"2斤"）, speed: "突然" |
| 食欲                         | appetite: "增加"                                | "减少"                                           |
| 运动 (ExerciseRecord)        | type, duration, frequency, intensity            | 活动量统计                                       |
| 饮食 (DietRecord)            | mealsRegular, water, caffeine, alcohol, smoking | 生活习惯                                         |
| 用药提及 (MedicationMention) | name, action: "服用"                            | "漏服"                                           |
| 生活事件 (LifeEventRecord)   | category, description, impact                   | 陪伴与归因，不直接进报告                         |
| 就医诉求 (medicalNeeds)      | string                                          | 预填报告“想解决的问题”                         |

## 三、完整数据结构（TypeScript 接口，来自材料第5节）

```Plain
// 每日对话提取结果（一天一条）—— 即“健康卡片”的数据结构


interface HealthRecord {
  date: string                       // YYYY-MM-DD，对话当天即时间锚点
  symptoms: SymptomRecord[]          // 身体症状（可多条）
  mood?: MoodRecord                  // 情绪
  sleep?: SleepRecord                // 睡眠
  menstrual?: MenstrualRecord        // 月经事件（不是每天都有）
  weight?: WeightRecord              // 体重（偶尔）
  appetite?: "增加" | "减少" | "正常"
  exercise?: ExerciseRecord          // 运动
  diet?: DietRecord                  // 饮食与饮品
  medications?: MedicationMention[]  // 用药提及
  lifeEvents?: LifeEventRecord[]     // 生活事件
  medicalNeeds?: string              // 就医诉求
}

// 各子结构见上文表格，此处不再重复
```

## 健康卡片数据库设计

基于你前面确认的健康卡片数据结构（TypeScript 接口），我为你设计了 **PostgreSQL** ** 数据库表结构** 。设计遵循以下原则：

* **每日一条主记录** （对应 `HealthRecord`），按 `user_id + date` 唯一
* **一对多子表** ：症状、用药提及、生活事件等（一天可有多个）
* **枚举类型** ：用 `CHECK` 约束或 `CREATE TYPE` 保证数据规范
* **JSONB 兜底** ：对于结构相对灵活或后续可能扩展的字段（如睡眠、情绪、饮食），使用 `JSONB` 存储，兼顾灵活性与查询效率
* **静态表单独立** ：`health_profile` 表存储导出时的静态资料，与动态记录分离

## 一、枚举类型（可选，也可用 CHECK）

```Plain
-- 程度枚举
CREATE TYPE severity_enum AS ENUM ('轻', '中', '重');
-- 趋势枚举
CREATE TYPE trend_enum AS ENUM ('加重', '减轻', '稳定');
-- 睡眠质量枚举
CREATE TYPE sleep_quality_enum AS ENUM ('好', '一般', '差');
-- 情绪类型
CREATE TYPE mood_type_enum AS ENUM ('负面', '正面');
-- 月经事件
CREATE TYPE menstrual_event_enum AS ENUM (
  '来了', '没来', '量多', '量少', '淋漓不尽', '非经期出血', '痛经', '停经'
);
-- 用药动作
CREATE TYPE medication_action_enum AS ENUM ('服用', '漏服', '停用');
-- 月经状态（用于静态表单）
CREATE TYPE menopausal_status_enum AS ENUM ('未绝经', '围绝经', '已绝经');
-- 药物状态
CREATE TYPE medication_status_enum AS ENUM ('服用中', '已停用', '偶尔服用');
```

## 二、核心表结构

1. ### 健康记录主表（每日一条）

```Plain
CREATE TABLE health_record (
  id          BIGSERIAL PRIMARY KEY,
  user_id     BIGINT NOT NULL,
  date        DATE NOT NULL,               -- YYYY-MM-DD
  appetite    VARCHAR(10) CHECK (appetite IN ('增加', '减少', '正常')),
  medical_needs TEXT,                      -- 就医诉求
  created_at  TIMESTAMPTZ DEFAULT NOW(),
  updated_at  TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE (user_id, date)                   -- 每日每用户一条
);
```

2. ### 身体症状表（核心，支撑月历曲线）

```Plain
CREATE TABLE symptom_record (
  id          BIGSERIAL PRIMARY KEY,
  record_id   BIGINT NOT NULL REFERENCES health_record(id) ON DELETE CASCADE,
  symptom     VARCHAR(50) NOT NULL,        -- 规范名，如"潮热"
  occurred    BOOLEAN NOT NULL DEFAULT TRUE,
  severity    severity_enum,               -- 轻/中/重
  frequency   VARCHAR(20),                 -- 如"3次"，原始描述
  frequency_count INTEGER,                 -- 数值槽："3次"→3；模糊词留空（曲线回退 severity）
  trend       trend_enum,                  -- 加重/减轻/稳定
  trigger     TEXT,                        -- 诱因
  quote       TEXT NOT NULL,               -- 原文片段
  created_at  TIMESTAMPTZ DEFAULT NOW()
);
-- 索引：按用户+日期+症状查询
CREATE INDEX idx_symptom_record_record_id ON symptom_record(record_id);
```

3. ### 睡眠记录表（独立表，非 JSONB，因为查询频繁）

```Plain
CREATE TABLE sleep_record (
  id          BIGSERIAL PRIMARY KEY,
  record_id   BIGINT NOT NULL REFERENCES health_record(id) ON DELETE CASCADE,
  quality     sleep_quality_enum,
  bedtime     TIME,
  wake_time   TIME,
  night_wakes INTEGER CHECK (night_wakes >= 0),
  detail      TEXT,                        -- 入睡难/早醒/多梦等
  created_at  TIMESTAMPTZ DEFAULT NOW()
);
```

4. ### 情绪记录表

```Plain
CREATE TABLE mood_record (
  id          BIGSERIAL PRIMARY KEY,
  record_id   BIGINT NOT NULL REFERENCES health_record(id) ON DELETE CASCADE,
  type        mood_type_enum NOT NULL,
  description VARCHAR(100) NOT NULL,        -- 如"烦躁"
  trigger     TEXT,                        -- 诱因
  created_at  TIMESTAMPTZ DEFAULT NOW()
);
```

5. ### 月经记录表

```Plain
CREATE TABLE menstrual_record (
  id          BIGSERIAL PRIMARY KEY,
  record_id   BIGINT NOT NULL REFERENCES health_record(id) ON DELETE CASCADE,
  event       menstrual_event_enum NOT NULL,
  event_date  DATE,                        -- 发生日期
  days_since_last INTEGER,                 -- 距上次天数
  note        TEXT,
  created_at  TIMESTAMPTZ DEFAULT NOW()
);
```

6. ### 体重记录表

```Plain
CREATE TABLE weight_record (
  id          BIGSERIAL PRIMARY KEY,
  record_id   BIGINT NOT NULL REFERENCES health_record(id) ON DELETE CASCADE,
  direction   VARCHAR(10) CHECK (direction IN ('增加', '减少')),
  amount      VARCHAR(20),                 -- 如"2斤"
  speed       VARCHAR(10) CHECK (speed IN ('突然', '缓慢')),
  record_date DATE NOT NULL,
  created_at  TIMESTAMPTZ DEFAULT NOW()
);
```

7. ### 用药提及表（动态）

```Plain
CREATE TABLE medication_mention (
  id          BIGSERIAL PRIMARY KEY,
  record_id   BIGINT NOT NULL REFERENCES health_record(id) ON DELETE CASCADE,
  name        VARCHAR(100) NOT NULL,
  action      medication_action_enum NOT NULL,
  created_at  TIMESTAMPTZ DEFAULT NOW()
);
```

8. ### 生活事件表

```Plain
CREATE TABLE life_event_record (
  id          BIGSERIAL PRIMARY KEY,
  record_id   BIGINT NOT NULL REFERENCES health_record(id) ON DELETE CASCADE,
  category    VARCHAR(20) CHECK (category IN ('家庭', '社交', '心情事件')),
  description TEXT NOT NULL,
  impact      VARCHAR(10) CHECK (impact IN ('正面', '负面', '中性')),
  created_at  TIMESTAMPTZ DEFAULT NOW()
);
```

9. ### 运动记录表

```Plain
CREATE TABLE exercise_record (
  id          BIGSERIAL PRIMARY KEY,
  record_id   BIGINT NOT NULL REFERENCES health_record(id) ON DELETE CASCADE,
  type        VARCHAR(50),                 -- 散步/广场舞等
  duration    VARCHAR(20),                 -- 如"30分钟"
  frequency   VARCHAR(20),                 -- 如"每周3次"
  intensity   VARCHAR(10) CHECK (intensity IN ('轻松', '适中', '累')),
  created_at  TIMESTAMPTZ DEFAULT NOW()
);
```

10. ### 饮食记录表（使用 JSONB 存储灵活字段）

```Plain
CREATE TABLE diet_record (
  id          BIGSERIAL PRIMARY KEY,
  record_id   BIGINT NOT NULL REFERENCES health_record(id) ON DELETE CASCADE,
  data        JSONB NOT NULL,              -- 结构见下
  created_at  TIMESTAMPTZ DEFAULT NOW()
);
```

`data` 字段示例：

```Plain
{
  "meals_regular": true,
  "foods": ["米饭", "青菜"],
  "water": "偏少",
  "caffeine": "咖啡2杯",
  "alcohol": "红酒半杯",
  "smoking": false
}
```

## 三、静态表单表（HealthProfile）

```Plain
CREATE TABLE health_profile (
  id                BIGSERIAL PRIMARY KEY,
  user_id           BIGINT NOT NULL UNIQUE,
  birth_year        INTEGER NOT NULL,
  height            NUMERIC(5,2),          -- 厘米
  menopausal_status menopausal_status_enum,
  chief_complaint   TEXT,                  -- 想解决的问题
  medical_history   TEXT[],                -- 数组：高血压、糖尿病等
  surgery_history   JSONB,                 -- [{name: "子宫切除", year: 2015}]
  allergies         TEXT[],                -- 过敏史
  pregnancy_history TEXT,
  family_history    TEXT,
  screenings        TEXT,                  -- 近期筛查
  created_at        TIMESTAMPTZ DEFAULT NOW(),
  updated_at        TIMESTAMPTZ DEFAULT NOW()
);

-- 用药清单（静态）
CREATE TABLE medication (
  id         BIGSERIAL PRIMARY KEY,
  profile_id BIGINT NOT NULL REFERENCES health_profile(id) ON DELETE CASCADE,
  name       VARCHAR(100) NOT NULL,
  dose       VARCHAR(50),
  frequency  VARCHAR(50),
  start_date DATE,
  status     medication_status_enum,
  reason     TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

## 四、月历曲线与报告生成的数据支撑说明

| 需求            | 数据来源表       | 关键字段                    | 聚合方式                                      |
| --------------- | ---------------- | --------------------------- | --------------------------------------------- |
| 潮热次数/天曲线 | symptom_record   | frequency_count（数值；无值回退 severity 等级） | 按 date 提取 health_record.date，计算每日次数 |
| 症状程度分布    | symptom_record   | severity                    | 众数/趋势                                     |
| 睡眠质量曲线    | sleep_record     | quality（可映射为1-3分）    | 直接绘图                                      |
| 夜醒次数曲线    | sleep_record     | night_wakes                 | 数值序列                                      |
| 情绪变化        | mood_record      | type, description           | 计数/分类                                     |
| 月经规律性      | menstrual_record | event_date, days_since_last | 计算周期长度                                  |

> 聚合窗口 = 报告导出时所选时间窗口（1 个月 / 3 个月 / 半年）。
